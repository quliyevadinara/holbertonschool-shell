# holbertonschool-shell

Bu repozitoriyada Holberton School üçün müxtəlif shell skriptləri var.  
Hər bölmə uyğun qovluqda saxlanılır; məsələn, `io_redirections_and_filters/0-hello_world` skripti "Hello, World" çap edir.

İstifadə:
```bash
./io_redirections_and_filters/0-hello_world
# Hello, World
```
